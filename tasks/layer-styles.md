# Complete Prism layer styles

Build on the existing gradient and drop-shadow foundation. Add ordered,
portable effects in reviewable slices: stroke and color/gradient overlay;
multiple/inner shadows and glows; then bevel/emboss and satin where stable
semantics can be defined. Keep architecture ready for patterns without claiming
pattern support before it exists.

Each slice needs core commands, CLI/schema and GUI parity, one semantic
revision per edit, bounded preview/region/export rendering, persistence and
transfer compatibility, visual fixtures, strict performance tests, and package
verification. See [prior scope](https://github.com/bentsignal/spectrum/issues/104).
